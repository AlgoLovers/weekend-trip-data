# weekend-trip-data

주말 가족여행 앱 **weekend-trip**이 받아 쓰는 공개 축제 데이터예요. 매일 00:05(KST)에 자동으로 갱신돼요.

- `festivals/<지역>.json` — 지역별 축제(회차별 날짜, 장소, 사진, 소개). 앱 데이터셋의 Festival 형식과 같아요.
- `state/<지역>.json` — 갱신에 쓰는 누적 상태(작년 회차 보존용).
- `scripts/festivals.py` — 만드는 스크립트(파이썬 표준 라이브러리만).

## 출처와 이용 조건

모든 데이터는 **한국관광공사 TourAPI 4.0**에서 받았어요(공공데이터포털). 사진은 공공누리 유형을 `license`로 표시해요.
`TYPE3`(변경금지) 사진은 자르거나 글씨를 얹지 말고, 출처 "한국관광공사"를 함께 표시해 주세요.

개인정보는 없어요. 앱은 이 파일을 받기만 하고 아무것도 올리지 않아요.
